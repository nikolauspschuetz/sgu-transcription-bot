# The Skeptics' Guide to the Universe (SGU)

American weekly **scientific-skepticism** podcast. The official podcast of the
**New England Skeptical Society (NESS)**.

| | |
|---|---|
| First episode | May 4, 2005 |
| Cadence | Weekly |
| Typical length | ~80 minutes |
| Host / producer | Steven Novella |
| Format | Panel discussion ("the Rogues") + interviews + games |

## What each episode covers

Recent science news, myths, conspiracy theories, pseudoscience, and paranormal
claims examined from a scientific-skepticism angle — frequently with an interview
of a scientist, author, or skeptic. Episodes open with a cold intro, run several
recurring segments (see [`segments.md`](segments.md)), and close with a
**Skeptical Quote** read by a host.

  maintainers before any real publish).

## Why this project targets SGU

The roster and segment structure are stable enough to model in templates, and the
show has a long back-catalogue (1000+ episodes) with a community transcript wiki —
a good fit for a local, free ASR + diarization pipeline. The motivating episode
for this fork is **#1096** (an AI-topics episode).
